## 1. Scope

## 2. Data We Collect

### 2.1 Deployment Data

When you deploy a Cotechnoe offer from Azure Marketplace, Microsoft Azure collects
deployment telemetry as described in the
[Azure Marketplace participation policies](https://azure.microsoft.com/en-us/support/legal/marketplace/).
Cotechnoe does **not** receive personally identifiable information (PII) about
individual deployers.

Azure may share aggregated, anonymized deployment statistics with publishers
(e.g., number of deployments per region). No personal data is included.

### 2.2 Support Requests

If you contact us at `support@cotechnoe.com`, we collect:

- Your name and email address (as provided by you)
- Your Azure subscription region and VM type (as provided by you)
- Technical details you include in your message

This data is used solely to respond to your support request and is not shared
with third parties.

### 2.3 GitHub Issues

If you open an issue on one of our GitHub repositories, your GitHub username and
issue content are publicly visible per
[GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

---

## 3. Data Hosted on Your VM

The virtual machine deployed from a Cotechnoe Marketplace offer runs entirely
within **your Azure subscription**. Any data you store in the wiki, database,
or application is hosted in your environment and under your control.

Cotechnoe does **not** have access to data stored on your deployed VM.

You are responsible for:

- Securing access to your VM (SSH keys, network security groups, firewall rules)
- Managing user credentials and access controls within the application
- Complying with applicable data protection regulations (GDPR, PIPEDA, etc.)
  for data you store on the platform

## 4. Cookies and Tracking
